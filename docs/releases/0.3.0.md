# v0.3.0 release evidence

Date: 2026-08-25 (UTC)

## Scope

`v0.3.0` adds the bounded Agent compatibility contract accepted in ADR 0015:
OpenAI-compatible function definitions, tool selection, tool-result turns,
streamed tool-call deltas, structured-output routing, the `rax/agent` alias,
and deny-by-default API-key tool permission. OpenAI, Anthropic, and Gemini
remain the supported provider adapters.

The Gateway translates tool traffic but does not execute tools, host MCP
servers, or implement the OpenAI Responses API. Agent runtimes retain their
own tool permissions, execution sandbox, memory, and control loop.

## Hosted evaluation boundary

The production `/demo/` page describes the v0.3.0 Agent path and links to its
integration guide. Its five-minute public credentials remain text-only,
non-streaming, and tool-disabled. A normal customer or self-hosted key must
explicitly enable Agent tool calls.

## Release artifacts

The signed `v0.3.0` tag starts the protected release workflow. It builds the
multi-architecture image, Helm chart, OpenAPI contract, source SBOM, checksums,
provenance, and keyless image signature. The workflow creates a draft GitHub
release so the operator can review immutable artifact metadata before making
the release public.
