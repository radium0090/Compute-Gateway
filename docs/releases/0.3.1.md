# v0.3.1 release evidence

Date: 2026-10-26 (UTC)

## Scope

`v0.3.1` is a maintenance release. It preserves the public API and accepted
architecture of `v0.3.0` while refreshing the pinned Node.js 24 build image,
runtime libraries, SDK compatibility clients, and CI/release actions.

No provider family, route surface, persistence model, or Agent execution
responsibility changes in this release. The gateway still translates bounded
OpenAI-compatible tool traffic but does not execute tools or persist request
content.

## Verification

The maintenance branch passes formatting, identity validation, lint, type
checking, unit coverage, build, OpenAPI/SDK consistency, compatibility,
performance, documentation, examples, and operations checks under Node.js 24.
The release-candidate pull request must also pass the repository's protected
PostgreSQL/Redis integration, container, Kubernetes, and security checks before
merge.

The Python OpenAI 3.x compatibility smoke remains part of the release gate so
the major client upgrade cannot be released solely on dependency resolution.

## Hosted evaluation boundary

The public AWS deployment is intentionally stopped between scheduled
evaluation windows to control cost. This release does not turn it on. A future
restart must deploy the immutable `v0.3.1` image by digest and repeat protected
provider, health, backup/restore, and public HTTPS verification before the
service is announced as available.

## Release artifacts

After the release-candidate checks pass, a signed `v0.3.1` tag starts the
protected release workflow. It builds the multi-architecture image, Helm chart,
OpenAPI contract, source SBOM, checksums, provenance, and keyless image
signature. The resulting draft GitHub release must be reviewed before it is
made public.
